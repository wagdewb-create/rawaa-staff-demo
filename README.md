https://rawaa-staff-demo.onrender.com/?rawaa_release=115

يُفتح في Safari على iPhone وفي متصفح الحاسوب مباشرة **دون تسجيل دخول**.

## إصدار المعاينة: 1.15
- التقرير الأسبوعي: اختيار بداية فترة من 7 أيام، تجميع الساعات الأساسية والإضافية والأجر لكل موظف، وتصدير CSV.
- تنتمي الوردية الليلية إلى يوم بدايتها، ولا تتكرر أول 8 ساعات إذا تعددت الورديات في اليوم الواحد.
- يتغير التقرير عند تعديل سجلات الدوام أو الموظفين.
- تم تحديث التخزين المؤقت للعمل دون إنترنت ليشمل `staff.js` و`daily-batch.js` و`weekly-report.js` بعد أول تحميل ناجح.

## RAWAA Cloud 2.2 | التحديث الآمن والنسخ المشفّرة (26 أكتوبر 2026)
- تفحص الأجهزة الأخرى السجلات السحابية كل 12 ثانية تقريبًا عندما يكون التطبيق مفتوحًا والاتصال متاحًا.
- يحدّث الجهاز غير النشط سجلاته تلقائيًا عندما يكون ذلك آمنًا؛ عند وجود تعديل في نموذج لم يُرسل يتوقف التحديث ويظهر تنبيه بدل مسح المدخلات.
- أصبحت النسخ الاحتياطية العادية ونسخة التعديلات غير المرسلة مشفّرة AES-256-GCM بكلمة مرور يحددها المدير، وتُستعاد داخل حسابه بعد التأكيد وفحص عدم تضارب التعديلات.
- يستمر دعم استعادة نسخ `rawaa-cloud-backup-v1` القديمة غير المشفّرة بعد موافقة صريحة، مع التنبيه إلى خطورتها. أما ملفات CSV والتصدير من أقسام التقارير فقد تبقى غير مشفّرة.
- لا يُشترط نقل البيانات أو إنشاء حساب جديد للانتقال من Cloud 2.0 إلى 2.2.

## RAWAA Cloud 2.0 | متعدد الأجهزة (26 أكتوبر 2026)

**رابط الواجهة السحابية:** https://rawaa-staff-demo.onrender.com/cloud.html

- تم إعداد Neon Auth (Better Auth) وNeon Data API على مشروع قاعدة بيانات RAWAA Staff Management Cloud المستقل.
- الجدول `public.rawaa_cloud_workspace_v1` لكل حساب بريد، مع RLS وصلاحيات SELECT/INSERT/UPDATE للحساب الذي يملك السجل فقط (لا توجد صلاحيات عامة).
- استخدم نفس بيانات الحساب على كل جهاز، لا يلزم إرسال كلمات المرور لأي شخص في المحادثة.
- لا تسمح المزامنة بتجاوز تعديلات جهاز آخر دون اكتشاف تعارض رقم النسخة؛ عند حدوث تعارض تتوقف الكتابة ويظهر إشعار.
- تنتظر العمليات تأكيد قاعدة البيانات؛ لا تغلق النافذة إذا كانت تظهر «جارٍ الرفع».
- خيار نقل خزنة الجهاز المشفرة 1.16 موجود على **نفس النطاق ومن نفس الجهاز** ولا ينقل شيئًا تلقائيًا. النقل لا يبدأ إلا عند موافقة المستخدم، ويتوقف إذا كانت هناك بيانات سحابية موجودة.
- يمكن تنزيل نسخة احتياطية مشفّرة واستعادتها يدويًا بموافقة صريحة، مع فحص تعارض نسخة السحابة قبل الاستبدال؛ تصدير CSV ونسخ JSON القديمة غير مشفّرة ويجب الاحتفاظ بها بأمان.
- لم نفتح حق الوصول لحسابات موظفين منفصلة ولا أدوار مشرفين بعد؛ تعدد الأجهزة يستخدم **نفس حساب المدير**.
- السحابة تتطلب اتصالًا؛ عند انقطاع الاتصال تفشل المزامنة ويحظر التطبيق الاستمرار إلى أن تُحل المشكلة.

## وضع العمل المحلي المشفر 1.16

**رابط وضع العمل على Render (تم التحقق من نشر الإصدار 1.16 بتاريخ 2026-10-26):**
https://rawaa-staff-demo.onrender.com/work.html

رابط النسخة التجريبية العامة (بيانات منفصلة): https://rawaa-staff-demo.onrender.com/

إن أردت استضافة GitHub Pages كخيار مستقل، يمكن لمالك المستودع تفعيلها عبر:
https://github.com/wagdewb-create/rawaa-staff-demo/settings/pages
ثم اختيار **Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save**.
هذا خيار إضافي **غير مطلوب** لاستخدام Render، ولا ينقل البيانات تلقائيًا بين النطاقين.

تم أيضًا تشغيل اختبار متصفح Chrome فعلي بنجاح باستخدام `node tests/work-browser.cjs` مع Playwright؛ شمل إنشاء كلمة مرور، حفظ اسم موظف مشفر، وإعادة فتح الصفحة واسترداد الاسم.

- شاشة قفل بكلمة مرور جديدة (12 حرفًا على الأقل)، مشتقة بمكتبة Web Crypto الأصلية (PBKDF2-SHA256، 310000 تكرار)، وتخزين محلي بمفتاح AES-GCM 256 بت وملح وIV عشوائيين.
- يتم عزل بيانات وضع العمل في قاعدة IndexedDB مشفرة، دون استخدام أسماء الموظفين في `localStorage` العادي، ودون إرسالها إلى خادم.
- الإبقاء على جميع الأقسام السابقة كما هي: الأسماء، الحضور والانصراف، الدوام الليلي، 8 ساعات عادية ثم 1.5× إضافي، السحوبات، الرواتب، التقارير والتصدير.
- أزرار لتنزيل نسخة مشفّرة واستعادة نسخة بعد فكها بكلمتها الصحيحة، وقفل جلسة العمل.
- مؤشر حفظ لتجنب افتراض أن بيانات الدوام محفوظة قبل اكتمال التشفير والكتابة.
- الصفحة قابلة للفتح دون إنترنت بعد زيارة موفقة أثناء الاتصال وتحميل أصول الـ PWA.
- النسخة التجريبية العامة `index.html` تظل منفصلة، ولا تحتوي على بيانات وضع العمل المشفر.
- **الحدود:** لا يوجد تسجيل دخول سحابي أو مزامنة أو نسخ احتياطي تلقائي على الخادم. فقدان كلمة المرور أو مسح بيانات Safari دون نسخة احتياطية يؤدي إلى فقد البيانات. لا تعتمد التطبيق لصرف رواتب نهائية قبل فحصه ببياناتك ونسخ احتياطي موثوق.

## وظائف المعاينة
- حساب ساعات حضور وانصراف كل موظف في أي يوم، مع دعم الورديات الليلية.
- لا توجد استراحة تُخصم من وقت الدوام.
- بعد أول 8 ساعات يومية يعمل حساب الإضافي بسعر 150% من أجر الساعة.
- كشف رواتب شهري، وسحوبات، ودفعات، وتقرير دوام يومي وأسبوعي وسنوي، وإدارة موظفين تجريبيين.
- تصدير CSV ونسخ JSON احتياطي للبيانات التجريبية.

## قيود الأمان (مهم جدًا)
- جميع أسماء الموظفين **وهمية**، ولا يوجد حساب مدير أو مزامنة عبر الإنترنت.
- يتم حفظ إدخالات المستخدم محليًا على الجهاز باستخدام المتصفح؛ لا تخزن فيها بيانات الموظفين الحقيقية.
- هذا المستودع عام وملفات الواجهة مفتوحة للجميع، ولا يجب وضع أسرار أو بيانات رواتب فيه.
- التطبيق لا يتصل بقاعدة بيانات RAWAA Windows 2.4، ولم يتم نقل أي بيانات حقيقية.
- لا تستخدم هذه المعاينة لإغلاق أو صرف رواتب فعلية.
