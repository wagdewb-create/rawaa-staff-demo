# RAWAA Staff Demo — رواء التجريبي

## فتح التطبيق
https://rawaa-staff-demo.onrender.com/

يُفتح في Safari على iPhone وفي متصفح الحاسوب مباشرة **دون تسجيل دخول**.

## وظائف المعاينة
- حساب ساعات حضور وانصراف كل موظف في أي يوم، مع دعم الورديات الليلية.
- لا توجد استراحة تُخصم من وقت الدوام.
- بعد أول 8 ساعات يومية يعمل حساب الإضافي بسعر 150% من أجر الساعة.
- كشف رواتب شهري، وسحوبات، ودفعات، وتقرير دوام يومي.
- تصدير CSV ونسخ JSON احتياطي للبيانات التجريبية.

## قيود الأمان (مهم جدًا)
- جميع أسماء الموظفين **وهمية**، ولا يوجد حساب مدير أو مزامنة عبر الإنترنت.
- يتم حفظ إدخالات المستخدم محليًا على الجهاز باستخدام المتصفح؛ لا تخزن فيها بيانات الموظفين الحقيقية.
- هذا المستودع عام وملفات الواجهة مفتوحة للجميع، ولا يجب وضع أسرار أو بيانات رواتب فيه.
- التطبيق لا يتصل بقاعدة بيانات RAWAA Windows 2.4، ولم يتم نقل أي بيانات حقيقية.
- لا تستخدم هذه المعاينة لإغلاق أو صرف رواتب فعلية.
